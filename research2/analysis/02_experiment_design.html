Experiment Design

Tasks, diversity axes, datasets, model families, and precision rollout metrics.

Tasks

Reach

The robot moves the end effector to a cube target. This task isolates visual target localization and closed-loop servoing.

Obstacle-aware reach

The robot must reach the same target while routing around a blocking obstacle. This introduces stage structure: hover, side alignment, and final descent.

Dataset Structure

Datasets are 128px behavior-cloning demonstrations collected from scripted experts. Each demonstration contributes image/action samples along the trajectory, not only the start and end states. The primary observations are external RGB and wrist/end-effector RGB, with robot state included in the policy input.

Budgets 5, 20, and 50 use seeds 0, 1, and 2. Budgets 100 and 200 use seed 0 only, so high-budget trends are directional rather than full multi-seed estimates.

Model Families

Model familyPurpose in the study
Scratch CNN BCMain pixel baseline trained end-to-end from 128px RGB observations plus robot state.
Frozen ResNet-18 BCPretrained encoder frozen; BC head learns from visual features. Tests whether generic visual features help in sim.
Partial ResNet-18 BCEarlier ResNet layers frozen, later layers and policy head trainable. Tests whether adaptation improves over frozen features.
Phase+geometry BCDiagnostic model with RGB, robot state, phase one-hot, target geometry, obstacle geometry, and relative deltas.

Evaluation Metrics

MetricInterpretation
S@0.5cm, S@1cm, S@2cm, S@5cmSuccess thresholds computed from the closest distance reached during the rollout.
Best distanceClosest end-effector-to-target distance ever reached. This measures whether the policy can get near the goal at all.
Final distanceDistance at rollout end. This measures whether the policy stabilizes or drifts away after getting close.
1mm stop thresholdRollouts only terminate early at 0.001 m, so S@5cm does not clip final distance near 5 cm.
